This is a Reaction Wheel Pendulum which is a type of self balancing inverted pendulum that uses a Fly Wheel. A Example image of one is below.

I acomplished creating this self balancing pendulum by using a Cypress 044 PSoC with a IMU communicated through I2C, BLDC motor w/ Encoder through I2C, and a TI Motor Driver.
